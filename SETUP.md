# Setup Guide

This repo powers the GitHub profile README at [github.com/vrelay](https://github.com/vrelay).

## Enable GitHub Actions

In **Settings → Actions → General**:
- Allow all actions and reusable workflows
- Allow GitHub Actions to create and approve pull requests (if prompted for write access)

## Refresh the profile

After pushing these workflow files, run each workflow once from the **Actions** tab:

| Workflow | What it writes |
|----------|----------------|
| **update profile cards** | `profile/stats.svg`, `profile/top-langs.svg`, `profile/streak.svg`, `profile/trophies.svg` |
| **generate activity graph** | `contributions.svg` on the `output` branch |
| **generate 3D contribution graph** | `profile-3d-contrib/profile-night-rainbow.svg` |
| **generate contribution snake** | `dist/github-contribution-grid-snake*.svg` |

Cards, trophies, the activity graph, the snake, and the 3D calendar are **SVG files in this repo**. They do not fetch live data when someone opens your profile. That is intentional: the public Vercel hosts for trophies, stats, and the activity graph were returning 402/500 or stale numbers (for example 8 commits and HTML-only language stats).

All four workflows also run automatically **twice a week** (Monday & Thursday, ~18:00–18:30 UTC).

After a workflow succeeds, wait ~30 seconds and hard-refresh your profile (`Ctrl+Shift+R` / `Cmd+Shift+R`).

## Why some numbers still differ

These cards measure different things:

| Number | Source | What it counts |
|--------|--------|----------------|
| ~1,331 total contributions | streak | GitHub contribution calendar (commits + PRs + issues + reviews, public) |
| ~1.2k commits trophy | trophies | Commit-based trophy score |
| Total Commits on the stats card | stats | Commits GitHub can attribute to `vrelay` (search/author email). Often lower than the calendar. |
| Stars / forks | stats + 3D graph | Stars and forks on repos you own (currently 8 / 3) |
| Top languages | languages card | Language bytes across **your** repos, not forks. HTML/CSS are hidden because generated markup was drowning out TypeScript / Python / Go. |

If Total Commits still looks far too low after a workflow run, the commit author email in git is probably not [linked to your GitHub account](https://github.com/settings/emails).

The 3D calendar sidebar (language pie, commit count) is generated by that workflow. Re-run **generate 3D contribution graph** if it still shows only Shell or a single-digit commit count — that was leftover from a partial API fetch, not your real stack.

Private contributions need a PAT (`repo` + `read:user`) stored as a repo secret and passed into the workflows instead of `GITHUB_TOKEN`.
